# Python Coding Task – Complete Solutions

This repository contains complete Python solutions for a 15-question coding assignment covering basic Python, control flow, loops, data structures, dictionaries, and comprehensions

##  Topics Covered

- FizzBuzz
- Leap year logic
- Equality vs identity (`==` vs `is`)
- XOR bitwise swap
- Prime number generation using `while`
- `pass`, `continue`, and `break`
- Grade classification using conditionals
- Reversing an integer using `%` and `//`
- Finding the runner-up score without sorting
- Removing duplicates from a list
- List intersection using `in`
- Tuple immutability and exception handling
- Character frequency counting
- List comprehension
- Dictionary comprehension

##  Assignment Sections

### Section 1 – Basic Python Concepts

1. **FizzBuzz Challenge** – Print numbers from 1 to 50, replacing multiples of 3 with `Fizz`, multiples of 5 with `Buzz`, and multiples of both with `FizzBuzz`.
2. **Leap Year Logic** – Check whether a given year is a leap year.
3. **Identity vs Equality** – Understand the difference between `==` and `is` using two lists.
4. **Bitwise Swap** – Swap two numbers using XOR without a third variable.

### Section 2 – Control Flow & Loops

5. **Prime Number Finder** – Find and print the first 10 prime numbers using a `while` loop.
6. **The Loop Breaker** – Practice `pass`, `continue`, and `break` in a loop from 1 to 20.
7. **Nested Conditionals** – Convert a numerical grade into `A`, `B`, `C`, or `Fail`.
8. **Reverse an Integer** – Reverse the digits of an integer using `while`, `%`, and `//`.

### Section 3 – Data Structures

9. **Runner-Up Score** – Find the second-highest score without using `sort()` or `sorted()`.
10. **Duplicate Removal** – Remove duplicate values from a list using a single line of code.
11. **List Intersection** – Find common elements between two lists using the membership operator `in`.
12. **Tuple Immutability Test** – Attempt to modify a tuple element and handle the resulting `TypeError`.

### Section 4 – Dictionaries & Comprehensions

13. **Character Frequency Counter** – Count the frequency of each character in a string.
14. **List Comprehension** – Generate squares of all even numbers between 1 and 20 in one line.
15. **Dictionary Comprehension** – Create a dictionary containing only items whose values are greater than 2.
